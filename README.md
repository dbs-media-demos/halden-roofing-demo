# Halden Roofing Co. — Scale by Noon concept site

A demo website for a **fictional** Fort Worth roofing contractor, built by [Scale by Noon](https://www.scalebynoon.com).
Live: https://halden-roofing-demo.vercel.app · Handoff notes: [`DEMO.md`](DEMO.md)

## Run

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
```

`NEXT_PUBLIC_NOINDEX` defaults to noindex (robots meta, `X-Robots-Tag`, robots.txt disallow). Set it to `false` only for a real client site.
`NEXT_PUBLIC_SITE_URL` defaults to `https://halden-roofing-demo.vercel.app`.

## Phones

Below 768 px or on a touch screen the homepage is a different cut of the same content, all in the "phone pass" block at the end of `src/app/globals.css` (section order, type, rails) and keyed on the same test as `isPhone()` in `src/lib/gsap.ts`. Pinned and scrubbed scenes become stacked sections. GSAP, Lenis and IBM Plex Mono are desktop-only and phones never fetch them, so keep them behind `loadGsap()`, `useIdleGSAP` or `isPhone()`. Desktop (1024 px and up) doesn't use any of it.

## 3D (desktop only)

The hero storm, the storm-damage story and the material explorer are one three.js scene (`src/components/fx/roof3d`, house and roofs built from primitives, textures painted on canvases, no model files). Nothing imports it statically: `src/lib/three-gate.ts` runs `import()` only after load on a big screen with a mouse, without reduced motion or Save-Data, so phones download zero bytes of three.js. Phones and other non-3D screens get stills rendered from the same scene (`public/images/3d`); after changing the scene, regenerate them with `_src/stills/render.mjs`.

## Where things live

- `src/content/*` — all copy: services, projects, cities, reviews, FAQs, materials, company facts
- `src/lib/site.ts` — business facts (name, phone, address, hours) · `seo.ts` / `schema.ts` — metadata + JSON-LD
- `src/components/sections/*` — page sections (Hero, StormStory, MaterialExplorer, ProjectsRail, ServiceMap…)
- `src/components/fx/roof3d/*` — the 3D house: geometry, roof coverings (shingle, metal, clay, slate), weather, scene
- `src/assets/photos/*` + `src/lib/photos.ts` — optimised photos (generated by `_src/optimize.mjs`), credits in `public/images/SOURCES.md`
- `src/app/display-font.css` — Archivo Expanded, inlined to avoid headline reflow

Forms validate and show success states but **send nothing**. Reviews, team and business details are fictional.
