# Halden Roofing Co. — Scale by Noon concept site

A demo website for a **fictional** Fort Worth roofing contractor, built by [Scale by Noon](https://www.scalebynoon.com).
Live: https://halden-roofing-demo.vercel.app · Handoff notes: [`DEMO.md`](DEMO.md)

## Run

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
```

`NEXT_PUBLIC_NOINDEX` defaults to noindex (robots meta, `X-Robots-Tag`, robots.txt disallow). Set it to `false` only for a real client site.
`NEXT_PUBLIC_SITE_URL` defaults to `https://halden-roofing-demo.vercel.app`.

## Phones

Below 768 px or on a touch screen the homepage is a different cut of the same content, all in the "phone pass" block at the end of `src/app/globals.css` (section order, type, rails) and keyed on the same test as `isPhone()` in `src/lib/gsap.ts`. Pinned and scrubbed scenes become stacked sections. GSAP, Lenis, the hero film and IBM Plex Mono are desktop-only and phones never fetch them, so keep them behind `loadGsap()`, `useIdleGSAP` or `isPhone()`. Desktop (1024 px and up) doesn't use any of it.

## Where things live

- `src/content/*` — all copy: services, projects, cities, reviews, FAQs, materials, company facts
- `src/lib/site.ts` — business facts (name, phone, address, hours) · `seo.ts` / `schema.ts` — metadata + JSON-LD
- `src/components/sections/*` — page sections (Hero, StormStory, MaterialExplorer, ProjectsRail, ServiceMap…)
- `src/components/house/HouseArt.tsx` — the SVG house shared by the storm story and material explorer
- `src/assets/photos/*` + `src/lib/photos.ts` — optimised photos (generated by `_src/optimize.mjs`), credits in `public/images/SOURCES.md`
- `src/app/display-font.css` — Archivo Expanded, inlined to avoid headline reflow

Forms validate and show success states but **send nothing**. Reviews, team and business details are fictional.
